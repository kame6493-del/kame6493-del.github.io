LINE の乗っ取りを防ぐ設定6つ

LINE の公式ガイド「LINEの乗っ取り被害を防ぐために!確認しておきたい3つのこと」では、ログイン中の端末と、ログインの通知を見ておくよう案内されています。

ここでは、LINE 公式のヘルプとガイドに書かれた設定を6つ並べました。上の2つは1分ほどで済みます。PC や iPad で LINE を使っている人は、ログイン許可をオフにすると入れなくなるので、注意書きを読んでから決めてください。

手順を確かめた日: 2026-10-31。各項目の下に、もとの公式ページの URL を載せています。

LINE・目安1分

1. ログイン許可(PC・iPad)

  1. [ホーム] を開く
  2. [設定] を押す
  3. [アカウント] を押す
  4. [ログイン許可] を見る
  5. PC などを使わないならオフにする

済んだ目印: 使わない人はオフになっていれば済み

オフのままだと: オンのままだと、ほかの端末からログインされるおそれがあります。

最初はオンです。オフにすると PC や iPad の LINE には入れなくなります。

手順の出典: LINEヘルプセンター「サブ端末（PC／タブレット）からの[ログイン許可]設定を変更するには？」https://help.line.me/line/smartphone/?contentId=20000112&lang=ja(確かめた日 2026-10-31)
注意の文の出典: LINEみんなの使い方ガイド https://guide.line.me/ja/features-and-columns/line-security.html(確かめた日 2026-10-31)

LINE・目安1分

2. パスコードロック

  1. [ホーム] を開く
  2. [設定] を押す
  3. [プライバシー管理] を押す
  4. [パスコードロック] をオンにする
  5. パスコードを2度入れる

済んだ目印: [パスコードロック] がオンなら済み

オフのままだと: ロックが無いと、スマホを開いた人にトークを見られるおそれがあります。

パスコードを忘れると LINE を入れ直すことになり、バックアップしていないトークが消えます。忘れない番号にしてください。

手順の出典: LINEヘルプセンター「LINEのパスコードロックを設定するには？」https://help.line.me/line/smartphone/sp?contentId=20023658&lang=ja(確かめた日 2026-10-31)

LINE・目安1分

3. ログイン中の端末

  1. [ホーム] を開く
  2. [設定] を押す
  3. [アカウント] を押す
  4. [ログイン中の端末] を押す
  5. 並んだ端末を見る

済んだ目印: 見覚えのない端末が無ければ済み

オフのままだと: 見ないままだと、知らない端末からのログインに気づけないおそれがあります。

見覚えのない端末は [ログアウト] を押し、パスワードを変えます。

手順の出典: LINEみんなの使い方ガイド「LINEの乗っ取り被害を防ぐために！確認しておきたい3つのこと」https://guide.line.me/ja/features-and-columns/line-security.html(確かめた日 2026-10-31)

LINE・目安2分

4. メールアドレスの登録

  1. [ホーム] を開く
  2. [設定] を押す
  3. [アカウント] を押す
  4. [メールアドレス] を見る
  5. 無ければ登録する

済んだ目印: 今使うメールが入っていれば済み

オフのままだと: 登録が無いと、機種変更の時に引き継げないおそれがあります。

登録はメインのスマホでします。届いた認証番号を入れると登録が済みます。

手順の出典: LINEみんなの使い方ガイド「メールアドレスの登録・変更方法」https://guide.line.me/ja/account-and-settings/account-and-profile/set-email-address.html(確かめた日 2026-10-31)
注意の文の出典: LINEヘルプセンター https://help.line.me/line/smartphone/sp?contentId=20000060&lang=ja(確かめた日 2026-10-31)

LINE・目安2分

5. パスワードの登録

  1. [ホーム] を開く
  2. [設定] を押す
  3. [アカウント] を押す
  4. パスワードが「登録済み」か見る
  5. 未登録なら画面に従って登録

済んだ目印: 「登録済み」なら済み

オフのままだと: 登録が無いと、機種変更やログインの時に困るおそれがあります。

同じ文字の続きを避け、英大文字・英小文字・数字・記号のうち3種類以上で8〜20文字にします。

手順の出典: LINEヘルプセンター「パスワード／メールアドレスを登録⋅確認⋅変更するには？」https://help.line.me/line/smartphone/sp?contentId=20000060&lang=ja(確かめた日 2026-10-31)

LINE・目安1分

6. ログインの通知

  1. トーク画面を開く
  2. LINE の公式アカウントを押す
  3. 届いたログインの通知を見る
  4. 身に覚えがあるか確かめる

済んだ目印: 身に覚えのない通知が無ければ済み

オフのままだと: 通知を見ないままだと、身に覚えのないログインに気づけないおそれがあります。

本物は名前「LINE」の左に緑の公式バッジがあります。身に覚えがなければ端末をログアウトし、パスワードを変えます。

手順の出典: LINEみんなの使い方ガイド「LINEの乗っ取り被害を防ぐために！確認しておきたい3つのこと」https://guide.line.me/ja/features-and-columns/line-security.html(確かめた日 2026-10-31)
注意の文の出典: LINEみんなの使い方ガイド https://guide.line.me/ja/cyber-bousai/(確かめた日 2026-10-31)

この点検を、アプリで順番に

トジマリは、スマホとお金まわりの設定を、ひとつずつ自分で確かめていくための Android アプリです。使っているサービスに印を付けると、このページと同じ公式ヘルプの手順が大きな字で1つずつ出て、済んだ所に印が付きます。親のスマホの分も分けて点検できます。

アプリは何も調べません。パスワードや暗証番号を入れる所もありません。点検の記録はスマホの中だけに残ります。
