介護福祉士国試のパート合格のしくみ。A・B・Cの科目と基準点、免除が続く期間

介護福祉士の国家試験は、第38回(2026年1月)から、全体の点数で不合格でも、パートごとの点数が基準を超えていれば、そのパートだけ合格になるしくみが入りました。試験センターの発表と第39回の受験の手引から、決まりを順に並べます。

先に要点を書きます。

  • 11の科目群を、A(60問)・B(45問)・C(20問)の3つのパートに分けて判定します。
  • 全パートを受けた人は、まず125点満点の総得点で判定し、そこで不合格なら、パートごとに判定します。
  • パートに合格するには、そのパートの基準点以上をとり、そのパートの科目群すべてで1点以上とることが条件です。
  • 合格したパートは、翌年と翌々年の試験で受けなくてよくなります。
  • 第39回で不合格パートだけを受けられるのは、第38回でパート合格した人だけです。

3つのパートと科目群

パートの中身は次のとおりです。配点は1問1点で、全体は125点です。問題番号は第38回の正答の発表での並びです。

パート科目群第38回の問題配点
A①人間の尊厳と自立、介護の基本 / ②社会の理解 / ③人間関係とコミュニケーション、コミュニケーション技術 / ④生活支援技術問1〜6060点
B⑤こころとからだのしくみ / ⑥発達と老化の理解 / ⑦認知症の理解 / ⑧障害の理解 / ⑨医療的ケア問61〜10545点
C⑩介護過程 / ⑪総合問題問106〜12520点

出典: 介護福祉士国家試験 合格基準(試験センター) / 第38回介護福祉士国家試験の合格基準及び正答について(試験センター・PDF)

科目群ごとの問題数は、第38回では、生活支援技術が26問でいちばん多く、医療的ケアが5問でいちばん少ない数でした。パートの合格にも「そのパートの科目群すべてで得点」が要るので、Bパートの医療的ケア(5問)、Cパートの介護過程(8問)のように問題の少ない科目群を0点にしないことが、全体の合格のときと同じく大切です。11の科目群の決まりは11の科目群と0点の決まりにまとめています。

判定の順番

全パートを受けた人は、2段階で判定されます。

  1. 総得点で判定します。第38回は、125点中64点以上で、11の科目群すべてで得点があれば合格でした。
  2. 1で不合格だった人は、パートごとに判定します。パートの基準点以上をとり、そのパートの科目群すべてで得点があれば、そのパートが合格になります。

不合格パートだけを受けた人は、受けたパートごとに、同じ基準点と科目群の条件で判定されます。

第38回のパートの基準点と、パート合格の人数

パートの基準点は、全パートを受けた人全員のパートごとの平均点の比率で、全体の合格点を分けて決めます。第38回は次の点でした(小数第2位まで)。

パート満点基準点パート合格の人数
A60点32.23点3,935人
B45点20.43点1,509人
C20点11.33点6,181人

出典: 第38回介護福祉士国家試験の合格基準及び正答について(試験センター・PDF) / 第38回介護福祉士国家試験の合格発表について(試験センター・PDF)

3つの基準点を足すと63.99点で、全体の合格点64点とほぼ同じになります。パート合格の人数は一部が重なっています。第38回の受験者は78,469人、合格者は54,987人(70.1%)で、この合格者とは別に、上の人数がパートだけ合格しました。

満点に対する基準点の割合は、Aが約54%、Bが約45%、Cが約57%です(上の表から計算)。第39回の基準点は、第39回の結果発表で決まります。

合格したパートが免除になる期間

合格したパートは、合格した年の翌年と翌々年の試験で免除されます。第38回でAに合格した人は、第39回と第40回でAを受けずにすみます。

受験の手引には「合格した最終年から2年間」とあり、全パートを選んで受け直し、同じパートにもう一度合格すると、その年から数え直しになります。受け直して今回は落としたときは、前の合格がそのまま有効です。

第39回で選べる受け方

第39回(2027年1月31日)の申し込みは9月2日で締め切られています。次の決まりは、第40回を受ける人にも同じ形で関わります。

  • 第38回でパート合格した人は、全パートを受けるか、不合格パートだけを受けるかを選べます。
  • 不合格パートの一部だけを受けることはできません。
  • 初めて受ける人、第38回で合格パートがなかった人、前に受けたのが第37回以前の人は、全パートを受けます。
  • 申し込んだあとに、受けるパートを変えることはできません。
  • 受験手数料は、全パートでも不合格パートだけでも同じ20,510円です。

受けるパートによって、試験の時間が変わります(障害等で時間の延長が認められた人は別の時間です)。

AとB / AとC午前にA(10:00〜11:45)、午後にBかC(Bは14:55まで、Cは14:20まで)

入室の時間や持ち物は第39回の受験票と当日の持ち物にまとめました。

残ったパートだけを勉強する人へ

ここからは、過去問アプリを作っている立場からの提案です。合格を約束するものではありません。

受けるパートが決まっている人は、そのパートの問題だけを過去問で回せば足ります。Cパートだけが残った人は、介護過程と総合問題の20問で、どれも事例を読んで答える問題です。第38回の基準点はCが11.33点だったので、20問中12問がひとつの目安になります。Bパートが残った人は、科目群が5つあり、医療的ケアの5問を落とさないことが先です。

間違えた問題に印をつけて、その問題だけを日を空けて解き直すと、残りの時間をそのパートの苦手に使えます。第38回の問題は正答と選択肢ごとの解説つきで1問ずつ載せています。

よくある質問

パートに全部合格したら、介護福祉士になれますか。

試験に合格しただけでは名乗れません。3つのパートがそろって合格になったあと、資格登録の申請をして登録を受ける必要があります(受験の手引)。

前の試験でどのパートに合格したか分かりません。

試験センターに電話で問い合わせるよう案内されています。電話番号は 03-3486-7521(平日9時30分〜17時)です。

全パートを受け直して、前に合格したパートを今回落としたら、前の合格は消えますか。

消えません。試験センターのよくある質問では、第38回で合格したパートは、第39回で不合格になっても第40回まで有効と答えています。

Bパートだけ、のように不合格パートの一部だけを受けられますか。

受けられません。たとえばAに合格してBとCが不合格だった人は、BとCの両方を受けるか、全パートを受けるかのどちらかです。

当日、申し込んだパートの一部を欠席したらどうなりますか。

受けなかったパートは採点されません。受験手数料は返ってきません。
