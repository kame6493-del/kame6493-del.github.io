親のスマホで、一緒に確かめたい設定

親のスマホの設定を、離れて暮らしていると確かめる機会がなかなかありません。会った時に、親のスマホを手元に置いて、この順番で一緒に見ていくための一覧です。

パスコードや暗証番号は、親のスマホの画面に親が自分で入れます。聞き出したり、どこかに書き残したりはしないでください。どれも1〜3分ほどです。

iPhone の場合

iPhone 本体・目安1分

1. 画面ロックのパスコード

  1. 「設定」を開く
  2. 「Face IDとパスコード」を押す
  3. パスコードを入れる
  4. 「パスコードをオフにする」の表示を見る

済んだ目印: 「パスコードをオフにする」と出ていれば済み

オフのままだと: ロックが無いと、なくした時に中を勝手に使われるおそれがあります。

ホームボタンのある機種は「Touch IDとパスコード」です。「パスコードをオンにする」と出ていたら、まだ設定されていません。

手順の出典: Apple サポート「iPhoneでパスコードを設定する」https://support.apple.com/ja-jp/guide/iphone/iph14a867ae/ios(確かめた日 2026-10-31)
注意の文の出典: Google アカウント ヘルプ https://support.google.com/accounts/answer/46526?hl=ja(確かめた日 2026-10-31)

iPhone 本体・目安2分

2. iOSを自動で最新に

  1. 「設定」を開く
  2. 「一般」を押す
  3. 「ソフトウェアアップデート」を押す
  4. 「自動アップデート」を押す
  5. 「自動インストール」をオンにする

済んだ目印: 「自動インストール」がオンなら済み

オフのままだと: 古いままだと、攻撃から守られないおそれがあります。

「ソフトウェアアップデート」の画面に、今の iOS の版と、新しい版があるかが出ます。

手順の出典: Apple サポート「iPhoneやiPadをアップデートする」https://support.apple.com/ja-jp/118575(確かめた日 2026-10-31)
注意の文の出典: Google アカウント ヘルプ https://support.google.com/accounts/answer/46526?hl=ja(確かめた日 2026-10-31)

iPhone 本体・目安1分

3. 「探す」をオンに

  1. 「設定」を開く
  2. 自分の名前を押す
  3. 「探す」を押す
  4. 「iPhoneを探す」を押す
  5. 「iPhoneを探す」をオンにする

済んだ目印: 「iPhoneを探す」がオンなら済み

オフのままだと: オフだと、なくした時に場所を調べられないおそれがあります。

同じ画面の「“探す”ネットワーク」もオンにすると、電波が無い時も探しやすくなります。

手順の出典: Apple サポート「iPhone、iPad、Macで「探す」を有効にする方法」https://support.apple.com/ja-jp/102648(確かめた日 2026-10-31)

Apple アカウント・目安1分

4. 2ファクタ認証

  1. 「設定」を開く
  2. 自分の名前を押す
  3. 「サインインとセキュリティ」を押す
  4. 「2ファクタ認証」を見る

済んだ目印: 「2ファクタ認証」がオンなら済み

オフのままだと: オフだと、パスワードが漏れた時にサインインされるおそれがあります。

ほとんどのアカウントは最初からオンです。

手順の出典: Apple サポート「Apple Accountの2ファクタ認証」https://support.apple.com/ja-jp/102660(確かめた日 2026-10-31)

Android の場合

Android 本体・目安1分

5. 画面ロック

  1. 設定アプリを開く
  2. [セキュリティ] を押す
  3. [画面ロック] を押す
  4. 今のロックの種類を見る

済んだ目印: PIN・パターン・パスワードのどれかなら済み

オフのままだと: 「なし」や「スワイプ」だと、中のデータが守られないおそれがあります。

Pixel は [セキュリティとプライバシー] > [デバイスのロック解除] > [画面ロック] です。[セキュリティ] が無い機種はメーカーの案内を見てください。

手順の出典: Android ヘルプ「Android デバイスで画面ロックを設定する」https://support.google.com/android/answer/9079129?hl=ja(確かめた日 2026-10-31)

Android 本体・目安2分

6. システムのアップデート

  1. 設定アプリを開く
  2. [システム] を押す
  3. [ソフトウェア アップデート] を押す
  4. 更新の状態を見る
  5. あれば画面の指示に沿って進める

済んだ目印: 新しい更新が無いと出ていれば済み

オフのままだと: 古いままだと、攻撃から守られないおそれがあります。

更新の前に Wi-Fi につなぎ、75% 以上充電しておきます。届く時期は機種・メーカー・通信会社で違います。

手順の出典: Android ヘルプ「Android のバージョンを確認して更新する」https://support.google.com/android/answer/7680439?hl=ja(確かめた日 2026-10-31)
注意の文の出典: Google アカウント ヘルプ https://support.google.com/accounts/answer/46526?hl=ja(確かめた日 2026-10-31)

Android 本体・目安2分

7. 提供元不明のアプリを許可しない

  1. 設定アプリを開く
  2. [アプリ] を押す
  3. [特別なアプリアクセス] を押す
  4. [不明なアプリのインストール] を押す
  5. 並んだアプリを1つずつ押す
  6. 「この提供元のアプリを許可」をオフにする

済んだ目印: どのアプリも許可がオフなら済み

オフのままだと: 提供元不明のアプリで、個人情報が流出するおそれがあります。

Pixel の画面の言葉です。他の機種は場所や名前が少し違うことがあります。

手順の出典: Google Pixel ヘルプ「Google Pixel にアプリをダウンロードする」https://support.google.com/pixelphone/answer/7391672?hl=ja(確かめた日 2026-10-31)
注意の文の出典: Android ヘルプ https://support.google.com/android/answer/7391672?hl=ja(確かめた日 2026-10-31)

Google アカウント・目安3分

8. 2段階認証プロセス

  1. Google アカウントを開く
  2. [セキュリティとログイン] を押す
  3. [Google にログインする方法] を見る
  4. [2 段階認証プロセス] の状態を見る

済んだ目印: 2段階認証プロセスがオンなら済み

オフのままだと: オフだと、パスワードを盗まれた時にログインされるおそれがあります。

オフなら [2 段階認証プロセスを有効にする] から画面の指示に沿って進めます。確認コードは人に教えないでください。

手順の出典: Google アカウント ヘルプ「2 段階認証プロセスを有効にする」https://support.google.com/accounts/answer/185839?hl=ja(確かめた日 2026-10-31)

LINE を使っているなら

LINE・目安1分

9. パスコードロック

  1. [ホーム] を開く
  2. [設定] を押す
  3. [プライバシー管理] を押す
  4. [パスコードロック] をオンにする
  5. パスコードを2度入れる

済んだ目印: [パスコードロック] がオンなら済み

オフのままだと: ロックが無いと、スマホを開いた人にトークを見られるおそれがあります。

パスコードを忘れると LINE を入れ直すことになり、バックアップしていないトークが消えます。忘れない番号にしてください。

手順の出典: LINEヘルプセンター「LINEのパスコードロックを設定するには？」https://help.line.me/line/smartphone/sp?contentId=20023658&lang=ja(確かめた日 2026-10-31)

LINE・目安1分

10. ログイン許可(PC・iPad)

  1. [ホーム] を開く
  2. [設定] を押す
  3. [アカウント] を押す
  4. [ログイン許可] を見る
  5. PC などを使わないならオフにする

済んだ目印: 使わない人はオフになっていれば済み

オフのままだと: オンのままだと、ほかの端末からログインされるおそれがあります。

最初はオンです。オフにすると PC や iPad の LINE には入れなくなります。

手順の出典: LINEヘルプセンター「サブ端末（PC／タブレット）からの[ログイン許可]設定を変更するには？」https://help.line.me/line/smartphone/?contentId=20000112&lang=ja(確かめた日 2026-10-31)
注意の文の出典: LINEみんなの使い方ガイド https://guide.line.me/ja/features-and-columns/line-security.html(確かめた日 2026-10-31)

この点検を、アプリで順番に

トジマリは、スマホとお金まわりの設定を、ひとつずつ自分で確かめていくための Android アプリです。使っているサービスに印を付けると、このページと同じ公式ヘルプの手順が大きな字で1つずつ出て、済んだ所に印が付きます。親のスマホの分も分けて点検できます。

アプリは何も調べません。パスワードや暗証番号を入れる所もありません。点検の記録はスマホの中だけに残ります。
