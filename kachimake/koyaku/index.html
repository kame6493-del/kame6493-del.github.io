スロットの小役カウンターの使い方と、小役確率の見方

2026年10月26日約4分で読めます

こんな人にスロットで小役を数えていて、出た確率をどう見ればいいか知りたい人

目次

  1. 数える前に決めておくこと
  2. 回転数が少ないうちは、数字は大きく揺れる
  3. 設定ごとの確率表と見比べるとき
  4. 数えた結果は収支と一緒に残す

小役カウンターでやっていることは単純で、回した回数と、ベルやチェリーが揃った回数を数えているだけです。数えた回数を総回転数で割れば、その日に実際に出た確率が 1/x の形で出ます。

小役の確率 = 1 / (総回転数 ÷ その小役の回数)
例: 3,000回転でベルが 400回 → 3,000 ÷ 400 = 7.5 → 1/7.5

難しいのは計算より、その数字をどこまで信じてよいかのほうです。このページでは、数え方でずれやすいところと、回転数によって数字がどれくらい揺れるのかを、架空の確率を使った計算でまとめておきます。実在の機種の数値は出てきません。

数える前に決めておくこと

総回転数は、自分が回した分だけを数えるのか、台のデータカウンターに出ている数字を使うのかを先に決めます。途中から座った台で、前の人の回転数まで入れてしまうと、小役の回数は自分の分だけなのに分母だけが大きくなり、確率が実際より低く出ます。小役を数えるなら、総回転数も自分が座ってからの分にそろえるのが基本です。

もう一つは、どの小役を数えるかです。全部の小役を数えようとすると押し忘れが増えます。機種の確率表を見て、設定ごとの差がある小役に絞ったほうが、数えた回数の質は上がります。押し忘れは数字を必ず低い方にずらすので、数が少ないより、数え漏れのほうが困ります。

回転数が少ないうちは、数字は大きく揺れる

小役の出方はくじ引きと同じで、本当の確率が決まっていても、数えた結果は毎回ばらつきます。どれくらいばらつくかは、回転数でほぼ決まります。

たとえば、本当の確率が 1/8.0 の小役があるとします。この小役を数えたときに、よくある範囲(およそ20回に19回はこの中に入る幅)は次のとおりです。

500回転: 1/6.5 〜 1/10.4
1,000回転: 1/6.9 〜 1/9.6
3,000回転: 1/7.3 〜 1/8.8
5,000回転: 1/7.5 〜 1/8.6

本当は 1/8.0 でも、1,000回転では 1/7.0 と出ることは珍しくありません。同じ表で、本当の確率が 1/7.2 の小役なら、1,000回転のときのよくある範囲は 1/6.2 〜 1/8.5 です。二つの範囲はほとんど重なっていて、1,000回転の数字だけでは、どちらの確率の台なのかはほぼ分かりません。3,000回転でもまだ重なりが残ります。

ボーナスのように確率の分母が大きいものは、もっと揺れます。本当の確率が 1/300 なら、3,000回転で出る回数の平均は10回ですが、4回でも16回でも普通に起こる範囲です。数回の差で判断するのは早すぎる、ということは覚えておいて損はありません。

設定ごとの確率表と見比べるとき

機種の雑誌やメーカーの公表値には、設定ごとの小役確率が載っていることがあります。数えた確率をこの表と見比べるときは、一番近い数字の設定を答えにするのではなく、「どの設定でも起こりうる数字か」「どの設定ではかなり起こりにくい数字か」を見るほうが実際に近い読み方です。

小役を一つだけで見るより、複数の小役とボーナスを合わせて見たほうが、偏りに引っぱられにくくなります。ただ、合わせて見ても、出てくるのは「この設定である見込みがどれくらいか」という割合で、決めつけられる答えではありません。数千回転を数えても外れることは普通にあります。

それから、設定の見込みが高く出たとしても、その日の収支がプラスになるとは限りません。台の性能はとても長い回転数をならしたときの話で、1日の結果はそれより何倍も大きく揺れます。カウンターの数字は、自分が何を見て判断したかを残しておくための記録と考えるのがちょうどいいと思います。

数えた結果は収支と一緒に残す

カウンターの数字は、その日の収支と並べて残しておくと、あとで読み返したときに役に立ちます。「この回転数でこの数字を見て続けた」「ここでやめた」という判断と、使った額・戻った額がセットで残っていれば、月末にまとめて振り返れます。収支の残し方は収支表のつけ方、月や期間で見る数字は回収率の出し方に書いています。

記録をつけるアプリ

カチマケパチンコ・スロット・競馬の収支

カチマケの小役カウンターは、総回転数を +1・+10・+50・+100 のボタンで足し、小役ごとに大きなボタンで数える形です。

数えている間はその場で 1/x の確率と出現率が出て、数え間違えたときはマイナスで戻せます。確率表は自分で入れて登録でき、終わったら「記録に反映」で回転数と回数をメモにして、その日の収支の記録に付けられます。数えることと実際の確率は誰でも使えます。設定ごとの見込みを出す計算は完全版の機能で、登録した確率と数えた回数だけから出す推測です。
