PayPay の乗っ取り・不正利用に備える設定5つ

PayPay の不正利用の話を見て、自分のアカウントは大丈夫かと気になった人に向けて、PayPay の公式ヘルプに書かれている設定の手順を並べました。

どれも、自分の PayPay アプリの画面で確かめる物です。ここに暗証番号やパスワードを書く所はありません。上限の金額は、ふだん使う分に合わせて選んでください。

2025年のフィッシングの報告件数: 245万4,297件警察庁(フィッシング対策協議会の集計)「令和7年におけるサイバー空間をめぐる脅威の情勢等について」資料(確かめた日 2026-10-31)

手順を確かめた日: 2026-10-31。各項目の下に、もとの公式ページの URL を載せています。

PayPay・目安2分

1. 使える金額の上限を決める

  1. ホーム画面右下の「アカウント」を押す
  2. 「利用可能額の設定」を押す
  3. もう一度「利用可能額の設定」を押す
  4. 「支払い」「友だちに送る」「チャージ」を見る
  5. それぞれ使う分に合う金額を選ぶ
  6. 上限に届いた時の動きを選ぶ

済んだ目印: 3つとも金額が決まっていれば済み

オフのままだと: 上限が無いと、不正に使われた時の被害が大きくなるおそれがあります。

古い版のアプリは先に「セキュリティとプライバシー」を押します。上限を上げる・外す時は、顔や指紋などの認証を求められます。

手順の出典: PayPay ヘルプ「自分で登録する利用可能額の設定方法」https://paypay.ne.jp/help/c0202/(確かめた日 2026-10-31)
注意の文の出典: PayPay https://paypay.ne.jp/safe/(確かめた日 2026-10-31)

PayPay・目安1分

2. 開く時の顔・指紋の認証

  1. ホーム画面の「アカウント」を押す
  2. 「セキュリティとプライバシー」を押す
  3. 「端末の認証を有効にする」を押す
  4. 画面の案内に従って認証を設定する

済んだ目印: PayPayを使う時に顔や指紋を聞かれれば済み

オフのままだと: 落とした時に、他の人にPayPayを使われるおそれがあります。

使える認証(顔・指紋・パスコード)は機種によって違います。

手順の出典: PayPay「PayPayの安全への取り組み(端末認証設定)」https://paypay.ne.jp/safe/(確かめた日 2026-10-31)

PayPay・目安2分

3. ログイン中の端末を見る

  1. ホーム画面の「アカウント」を押す
  2. 「セキュリティとプライバシー」を押す
  3. 「端末の管理」を押す
  4. 「認証済みの端末」のタブを見る
  5. 心当たりのない端末は「削除」を押す

済んだ目印: 知らない端末が一覧に無ければ済み

オフのままだと: 知らない端末が残っていると、勝手に使われるおそれがあります。

自分のスマホも「iPhone」や「Generic Smartphone」の名前で出ます。古い版は「ログイン管理」という名前です。全部の端末からログアウトすると、入り直す時にSMS認証が要ります。

手順の出典: PayPay ヘルプ「端末の管理機能について」https://paypay.ne.jp/help/c0295/(確かめた日 2026-10-31)
注意の文の出典: PayPay https://paypay.ne.jp/safe/(確かめた日 2026-10-31)

PayPay・目安3分

4. 登録した口座・カードの確認

  1. ホーム画面の「アカウント」を押す
  2. 「支払い方法の管理」を押す
  3. 上の画像を横にずらして全部見る
  4. 使わない物は右下の「有効」を押す
  5. 内容を見て無効にする

済んだ目印: 知らない口座・カードが無ければ済み

オフのままだと: 覚えのない口座やカードがあると、不正な取引に気づくのが遅れるおそれがあります。

無効にした物は「無効」を押すとまた使えます。PayPayクレジットは無効にできません。

手順の出典: PayPay ヘルプ「支払い方法(クレジットカード・チャージ用口座)を削除・無効化したい」https://paypay.ne.jp/help/c0067/(確かめた日 2026-10-31)
注意の文の出典: 金融庁 https://www.fsa.go.jp/ordinary/internet-bank_2.html(確かめた日 2026-10-31)

PayPay・目安2分

5. オートチャージの中身

  1. ホーム画面の「チャージ」を押す
  2. 「オートチャージ設定」を押す
  3. いまの設定の状況を見る
  4. チャージ元と金額に覚えがあるか確かめる

済んだ目印: 設定の中身に全部覚えがあれば済み

オフのままだと: 設定を忘れていると、心当たりのないチャージに見えることがあります。

Yahoo!フリマ・Yahoo!オークションの売上金をチャージする設定もここで確かめます。

手順の出典: PayPay ヘルプ「心当たりないチャージがある」https://paypay.ne.jp/help/c0540/(確かめた日 2026-10-31)

この点検を、アプリで順番に

トジマリは、スマホとお金まわりの設定を、ひとつずつ自分で確かめていくための Android アプリです。使っているサービスに印を付けると、このページと同じ公式ヘルプの手順が大きな字で1つずつ出て、済んだ所に印が付きます。親のスマホの分も分けて点検できます。

アプリは何も調べません。パスワードや暗証番号を入れる所もありません。点検の記録はスマホの中だけに残ります。
