過去問の解き方

どの資格試験でも言われることですが、過去問は「何年分を解いたか」より「間違えた問題をどれだけ解けるようにしたか」で差がつきます。以下は特定の教材に限らない、一般的な進め方です。

最初に、いちばん新しい第115回を通しで解く

最初の1回は、第115回の240問を午前と午後に分けて通しで解いてみるのがおすすめです。本番は午前・午後とも120問を2時間40分で解きます。答え合わせのときは、必修問題の点と、一般問題・状況設定問題の点を分けて出しておきます。

必修問題は、8割を毎回超えられるかで見る

必修問題は5回とも、50点中40点(採点除外があった回は49点中40点)が基準でした。一般・状況設定の点がどれだけ高くても、必修が1点足りなければ不合格です。必修の点は、解くたびに40点と並べて、届かない回があればそこから手をつけます。

間違えた問題と、迷って当たった問題を残しておく

×だった問題に加えて、勘で当たった問題にも印をつけます。状況設定問題は同じ事例に3問ずつつながっているので、1問落としたら、同じ事例の残りの2問も一緒に見直すと、読み違えた所が分かりやすくなります。

日を空けて、2回続けて正解するまで解き直す

解説を読んだ直後に解き直すと、ほぼ正解します。翌日や数日後にもう一度解いて、2回続けて正解できたらリストから外す、という決まりにしておくと、覚えたかどうかで迷わずに済みます。

合格率の高さに安心しすぎない

第115回の合格率は88.3%ですが、新卒以外に限ると約32%でした。実習や卒業研究で時間が取りにくい時期は、苦手リストの解き直しだけでも毎日続けておくと、直前に慌てずに済みます。

第116回(2027年2月14日)までの進め方の一例

10月から始める場合の目安です。もっと前から始めている人は、各月の内容を前に倒してください。

  1. 10月〜11月第115回を通しで1回。必修と一般・状況設定の点を分けて記録し、苦手リストを作り始める。11月6日から27日の間に願書を出す。
  2. 12月第114回・第113回へ。必修は毎回40点を超えるまで解き直す。
  3. 1月残りの回を解き終える。状況設定問題で落としている領域を重点的に。受験票が1月29日までに届かなければ問い合わせる。
  4. 2月新しい問題は増やさず、苦手リストと第115回の解き直しに絞る。直前の週末にもう一度、通しで解く。

あわせて読む: 必修問題(50問・40点以上)の基準と、一般・状況設定の合格点の決まり方 / 第116回 願書の提出期間(11月6日〜27日)・写真の決まり・出す書類・あと何日 / 試験まで3か月。必修40点と合格点から考える勉強の順番

過去問アプリ「ニガテ帳」について

ここまでの解き方を、スマホでやりやすくするために作ったアプリです。間違えた問題が「苦手」として残り、日を空けて2回続けて正解すると消えます。科目ごとの正答率と、いまの正答率で本番を受けたら何点になるかの予想も出ます。点数が上がるかどうかは使い方しだいなので、効果や合格をお約束するものではありません。

ニガテ帳

この試験の過去問を、間違えた問題だけ残して解ける iPhone アプリ(アプリの中で試験を選べます)

  • 収録: 看護師国家試験 第111回〜第115回の1,200問。全問に解説つき(解説は独自に書いたものです)
  • すぐ解ける: 第115回の240問を、解説・苦手の記録・予想点まで含めて使えます
  • 広告なし、アカウント登録なし。記録は端末の中だけに保存され、電波のない所でも解けます

必修問題は8割の基準と、一般・状況設定は合格点と、別々に並べて予想点を出します。図のある問題も画像で収録しています。
