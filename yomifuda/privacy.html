よみふだ プライバシーポリシー

最終更新日: 2026年10月11日

「よみふだ」(百人一首の読み上げアプリ。以下「本アプリ」)は、利用者の情報を次のとおり扱います。

集める情報

本アプリは、氏名・メールアドレス・位置情報・連絡先など、利用者を特定できる情報を集めません。アカウントの登録もありません。

端末の中に保存する情報

読み方の設定、途中まで読んだ札の順番、対戦の記録(利用者が入力した名前と取った枚数、メモ)は、お使いの端末の中だけに保存します。開発者のサーバーを含め、外部には送りません。アプリを削除すると消えます。

読み上げの音声

読み上げには端末に入っている音声合成の機能を使います。本アプリがマイクを使ったり、音声を録音したりすることはありません。端末の設定によっては、音声合成のサービス(端末の製造元や OS の提供元)がネットワークを使う声を提供している場合があり、その場合の扱いはそれぞれの提供元の方針によります。

アプリ内課金

「よみふだ プラス」の購入と復元には、Apple の App Store または Google Play の決済を使い、購入の確認のために RevenueCat, Inc. のサービスを使います。このとき、購入の記録と、アプリが作る匿名の利用者 ID が RevenueCat に送られます。氏名・メールアドレス・支払いの情報を本アプリが受け取ることはありません。

RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy

データの削除のお願い(よみふだ)

よみふだが外部に送るデータは、購入の確認のために RevenueCat に送られる「匿名の利用者 ID」と「購入の記録」だけです。削除を希望するときは、次の手順でお知らせください。

  1. kame6493@gmail.com へ、件名「よみふだ データ削除」でメールを送ってください。
  2. 本文に、購入した日とストアの名前(App Store または Google Play)、ストアから届いた領収書の注文番号を書いてください。購入していない場合の匿名の利用者 ID は、ほかの情報と結び付かないため、こちらで特定して消すことができません。アプリを削除すると、その端末の ID は使われなくなります。
  3. 受け取ってから30日以内に、RevenueCat 上の利用者 ID と購入の記録を削除し、メールでお知らせします。

削除の依頼がない間、これらのデータは購入の確認と復元のために保持します。端末の中の設定と記録は、アプリを削除すると消えます。Apple・Google が持つ購入の記録は、それぞれの会社の方針で扱われます。

広告・解析

広告は表示しません。利用状況の解析・追跡のためのツールも使いません。

子どもの利用

本アプリは家庭や学校でのかるた遊びに使われることを想定しています。子どもの個人情報を集めることはありません。
