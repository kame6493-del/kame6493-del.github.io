かんじさん プライバシーポリシー

最終更新日: 2026年10月11日

「かんじさん」(宴会の幹事アプリ。以下「本アプリ」)は、利用者の情報を次のとおり扱います。

集める情報

本アプリは、氏名・メールアドレス・位置情報・連絡先など、利用者を特定できる情報を集めません。アカウントの登録もありません。

端末の中に保存する情報

席決めや景品くじのために利用者が入力した参加者の名前・性別や部署のメモ、景品、進行表、ビンゴと当選の記録、設定は、お使いの端末の中だけに保存します。開発者のサーバーを含め、外部には送りません。アプリを削除すると消えます。

印刷用カードの PDF や記録の書き出し(CSV)は、利用者が共有の画面で選んだ先(印刷・保存・送信など)にだけ渡ります。

アプリ内課金

「幹事セット」の購入と復元には、Apple の App Store または Google Play の決済を使い、購入の確認のために RevenueCat, Inc. のサービスを使います。このとき、購入の記録と、アプリが作る匿名の利用者 ID が RevenueCat に送られます。氏名・メールアドレス・支払いの情報を本アプリが受け取ることはありません。

RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy

データの削除のお願い(かんじさん)

かんじさんが外部に送るデータは、購入の確認のために RevenueCat に送られる「匿名の利用者 ID」と「購入の記録」だけです。削除を希望するときは、次の手順でお知らせください。

  1. kame6493@gmail.com へ、件名「かんじさん データ削除」でメールを送ってください。
  2. 本文に、購入した日とストアの名前(App Store または Google Play)、ストアから届いた領収書の注文番号を書いてください。購入していない場合の匿名の利用者 ID は、ほかの情報と結び付かないため、こちらで特定して消すことができません。アプリを削除すると、その端末の ID は使われなくなります。
  3. 受け取ってから30日以内に、RevenueCat 上の利用者 ID と購入の記録を削除し、メールでお知らせします。

削除の依頼がない間、これらのデータは購入の確認と復元のために保持します。端末の中の設定と記録は、アプリを削除すると消えます。Apple・Google が持つ購入の記録は、それぞれの会社の方針で扱われます。

広告・解析

広告は表示しません。利用状況の解析・追跡のためのツールも使いません。

子どもの利用

本アプリは子ども向けに作ったものではありません。子どもの情報を特別に集めることもありません。
