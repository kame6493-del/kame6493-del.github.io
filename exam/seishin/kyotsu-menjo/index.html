社会福祉士・精神保健福祉士の共通科目の免除。何問になり、合格点はどう変わるか

2026年10月26日約4分で読めます

こんな人に社会福祉士か精神保健福祉士の資格を持っていて、もう一方を受けようとしている人

目次

  1. 免除される12科目

  4. 受験手数料と試験の時間(社会福祉士 第39回・精神保健福祉士 第29回)
  5. 免除で受ける人の勉強
  6. よくある質問

社会福祉士と精神保健福祉士の国家試験には、共通の12科目があります。どちらかの資格で登録を受けている人は、もう一方の試験を受けるとき、申請すればこの12科目が免除されます。何問が免除になり、合格点がどう変わるかを、試験センターの発表から並べます。

先に要点を書きます。

  • 免除されるのは共通科目12科目、問題数にすると84問です。
  • 社会福祉士は129問が45問に、精神保健福祉士は132問が48問になります。
  • 合格点は免除の人だけ別に決まります。第38回社会福祉士は45点中17点、第28回精神保健福祉士は48点中27点でした。
  • 条件は、もう一方の資格の登録を受けていることです。申し込みのとき免除申請を「有」にし、登録番号を入れます。

免除される12科目

医学概論 / 心理学と心理的支援 / 社会学と社会システム / 社会福祉の原理と政策 / 社会保障 / 権利擁護を支える法制度 / 地域福祉と包括的支援体制 / 障害者福祉 / 刑事司法と福祉 / ソーシャルワークの基盤と専門職 / ソーシャルワークの理論と方法 / 社会福祉調査の基礎

この12科目は、社会福祉士の試験では午前の84問、精神保健福祉士の試験では2日目午前の84問にあたります。免除を受けると、受けるのは専門科目だけです。

合格点は、どちらも満点の6割程度を基準に、問題の難しさで補正して決まります。第38回社会福祉士の免除者の合格点17点は45点の約38%、第28回精神保健福祉士の免除者の合格点27点は48点の約56%でした(上の表から計算)。全科目の人の合格点の割合(社会福祉士約39%、精神保健福祉士約47%)と、同じ年でも同じになるとは限りません。

科目群の条件も変わる

点数のほかに、すべての科目群で得点していることが合格の条件です。免除を受けた人は、専門科目の科目群だけが対象になります。

時間は、時間の延長がない人のものです。第39回・第29回の申し込みは2026年10月2日で締め切られています。次の回を考えている人は、免除の申請に登録番号が要ることを先に確かめておくと、申し込みで迷いません。

免除で受ける人の勉強

ここからは、過去問アプリを作っている立場からの提案です。合格を約束するものではありません。

免除で受ける人の問題は45問か48問で、1問の重みが全科目の人より大きくなります。専門科目の科目群は数が少ないので、どの科目群も0点にしないことが先です。精神保健福祉士の専門科目は今の形で第27回と第28回の2回分、社会福祉士の専門科目は第37回と第38回の2回分があります(精神保健福祉士の科目ごとの問題数 / 社会福祉士の科目ごとの問題数)。

第28回の精神保健福祉士の問題は正答と解説つきで1問ずつ、社会福祉士は試験ページから年度ごとに見られます。

よくある質問

国家試験に合格しただけで、まだ登録していません。免除を受けられますか。

免除の条件は、もう一方の資格の「登録を受けていること」で、申し込みには登録番号が要ります。登録申請中の人や、登録日が申し込み年の9月1日以降の人は試験センターに問い合わせるよう案内されています(第39回・第29回の案内)。

免除は自動でつきますか。

つきません。インターネットの申し込みの途中で、科目免除申請を「有」にします。「無」を選ぶと免除されません。

免除を受けると、合格点はどう決まりますか。

免除を受けた人だけの満点(社会福祉士45点、精神保健福祉士48点)に対して、6割程度を基準に難しさで補正した点が合格点になります。第38回社会福祉士は17点以上、第28回精神保健福祉士は27点以上でした。

両方を一度に受けることはできますか。

できます。同時受験は北海道・宮城県・東京都・愛知県・大阪府・広島県・福岡県の7試験地で、土曜と日曜の2日間です。申し込みで「社会福祉士国家試験と精神保健福祉士の同時受験」を選びます。
